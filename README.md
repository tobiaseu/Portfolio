# Tobia Seu — Portfolio

Personal portfolio: a 3D sphere of projects, scroll choreography and project pages.
Single-file site (`index.html`) built with HTML, CSS, JavaScript and [GSAP](https://gsap.com/) (loaded from a CDN).

## Structure

- `index.html` — the whole site
- `img/` — project photos (`<id>-cover.jpg`, `<id>-1.jpg` …) and portrait (`tobia.jpg`)
- `cv/` — CV in PDF

## Run locally

Open `index.html` in a browser (an internet connection is needed for GSAP).
